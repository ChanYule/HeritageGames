# Singapore Heritage Games

A browser-based collection of four playable heritage games:

- Marbles
- Pick-Up Sticks
- Five Stones
- Chapteh

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Controls

### Marbles
Drag backwards from the white shooter marble and release.

### Pick-Up Sticks
Drag an exposed stick far enough away from the pile to collect it.

### Five Stones
Press Toss, tap the required number of ground stones, then tap the airborne stone before it lands.

### Chapteh
Press A / Left Arrow for the left foot and D / Right Arrow for the right foot. On touch screens, tap the left or right side of the play area.

## Technology

- React
- TypeScript
- Vite
- HTML5 Canvas
- Pointer Events

No backend is required.
